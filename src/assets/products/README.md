# Ready-made products

Put up to 20 product photos here (`.jpg`, `.jpeg`, `.png` or `.webp`). They
show up in the rail beside the phone in file-name order, and the file name is
the label:

| File | Shows as |
| --- | --- |
| `01-brass-diya.jpg` | Brass diya, first |
| `02-madhubani_painting.jpg` | Madhubani painting, second |
| `terracotta pot.png` | Terracotta pot |

The leading number only sets the order and is not shown. Anything past the
twentieth file is ignored.

Photos of the product on its own, against a plain wall, floor or cloth, get
through the pipeline's photo check. Busy scenes (a market stall, a potter's
yard) are sent back with a retake note.

Keep each file under about 500 KB. They ship with the site, and the rail only
shows them as small squares. The pipeline gets its own copy, scaled to 1600px
on the longest side.

If you use someone else's photo, note its licence and credit here.
